This independent project seeks to identify correlations between blood glucose concentrations and insulin concentrations, and to test predictive regression models and their statistical significance in making accurate predictions for diabetic patients.

This project was my first foray into Python coding in the context of scientific modelling and data analysis. It began as an independent venture into practising and refining my Python skills in the domains of biomedicine, biochemistry, and biotechnology, which are of particular interest to me.

The dataset for this project was obtained from Kaggle and was originally sourced from the National Institute of Diabetes and Digestive and Kidney Diseases. The original dataset was a comprehensive collection of measurements used to test correlations between diabetes prevalence and a variety of physiological factors.

The paper utilised regression models of varying complexity and employed residual analysis to test their statistical significance. Subgroup comparisons were also conducted to determine whether they would yield better model fits than increasing model complexity alone.

Through the aforementioned analysis, it was concluded that there was strong statistical evidence to suggest that subgroup division of the global dataset on the basis of diabetes status plays a larger role in predictive modelling than model complexity itself.

This repository contains the code utilised to analyse the dataset alongside the final report produced to explain my findings and models.

This project demonstrates my Python skills in the areas of data analysis, computational modelling, and the scientific reporting of analytical findings.
